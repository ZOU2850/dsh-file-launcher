# dsh-file-launcher（文件启动器）

一个 DeepSeek Harness 右侧边栏的**文件启动器**：把「这个对话产出了哪些文件、交付了哪些文件、我发了哪些附件、工作区里有哪些文档」收进一个面板，并直接预览、用本机软件打开、在资源管理器中定位、加入输入框引用、收藏防上下文压缩、归档备份。

## 功能

- **当前对话 / 我发送的 / 当前项目 / 收藏 / 历史对话** 五个范围。**我发送的** 会扫描最近 20 个顶层会话，跨所有项目汇总用户发送的文件与图片，并按 **项目 → 会话** 折叠分组；历史对话同样按项目分组，可折叠展开。
- **从会话日志自动发现文件**：`present` 交付、`write`/`edit`/`apply_patch` 结果、读取过的文件、用户发送的普通文件、`@路径` 文件/文件夹与图片。
- **一个「筛选」按钮**打开主从面板：左边**来源**是父级（交付/用户/生成/参考/工作区…），右边**类型**嵌在当前来源下。父级数字保持稳定，子级数字按父来源、搜索和已归档实时计算；选中的筛选显示为可移除标签，**清除全部**一键复位。
- **我发送的 / 当前项目按“项目 → 会话”分组**。「我发送的」支持组头和会话头折叠，且可设置**默认收起**，打开面板先看到项目目录；**当前项目**在单一项目下自动展开外层分组，免去无谓折叠点击。搜索或任一筛选生效时会自动展开匹配分组，筛选只作用于组内文件，组头数字随筛选更新。
- **用户 @ 路径会被解析**：文件归入用户文件并标记 **引用**，同时出现在 **用户** 与 **我发送的**；点引用标签或右键 **追溯引用位置** 可查看来源会话、项目、消息位置、时间和原始文本。文件夹显示为文件夹行并提供 **在资源管理器中打开**；未知/特殊扩展名自动分类为程序、设计文件、数据库、字体、磁盘镜像、二进制、文件夹等。支持 `@路径`、`@"带空格路径"` 和紧跟在中文后的 `@"..."`。
- **工作区文档扫描**：Word、PowerPoint、Excel、PDF、Markdown、文本、图片、HTML、音视频、压缩包及特殊文件；自动跳过 `node_modules`、`.git`、构建产物与隐藏目录。
- **面板打开时定时刷新**：默认每 **60 秒** 自动轮询当前范围（可在设置中调整 5–300 秒或关闭），复用 Host 短时缓存避免卡顿；显式点击「刷新」时绕过缓存（`fresh=1`）。「我发送的」会先合并当前会话。
- **文件删除后保留空壳**：用户发送/交付的文件消失后保留为 **不存在** 行，显示最后路径，不会直接消失；通过插件删除的文件会记录 tombstone，不会以空壳回来。移盘后如果新路径在同一会话里再次出现且文件名+大小一致，会尝试关联为 **已移动**；跨盘移动且没有新引用时无法自动发现，会保留空壳，直到重新发送新路径或手动清理。
- **PDF/Office 页面预览**工具栏常驻：上一页/下一页、页码、缩放、适合宽度、在侧边栏打开、关闭；点击外部不会关闭，页面内右键可弹菜单。
- **面板内预览**图片、PDF、Markdown、文本，以及经 Host `office-kit` 转 PDF 再渲染成页面的 Word/PowerPoint/Excel；图片支持「上一个 / 下一个」和键盘 `←` / `→`。
- **常驻行操作 + 浮动右键菜单**：右键或点 **打开方式 ▾** 会在点击位置弹出可滚动卡片，包含预览、本机打开、资源管理器、关联软件、复制、收藏、归档和 **删除文件**。
- **历史对话全局返回**：从项目进入会话后，标题栏左侧的 `←` 可返回历史项目列表。
- **预览内右键**：图片预览中右键同样弹出操作卡片，可复制图片、复制路径、插入引用、收藏、归档、删除。
- **删除需确认**：明确确认后才从硬盘永久删除，并同步移除收藏记录与归档标记；不会误删。
- **打开方式**：按文件关联列出本机软件；可在资源管理器中显示；Windows 下可呼出系统原生「选择打开方式」。
- **加入输入框 / 插入引用**：优先通过宿主可选的 `fileDrag` 服务作为真实文件附件加入输入框；若宿主未提供或无拖放目标，则自动回退写入可退格删除的 `@路径` 文本或复制到剪贴板。
- **收藏（只保护路径记忆）**：写入 `$DSH_HOME/file-launcher/pins.json`；文件始终留在硬盘，收藏不会移动或删除文件，上下文压缩只压缩记忆、不影响文件。
- **归档（只复制副本）**：优先复制到 `$DSH_FILE_LAUNCHER_ARCHIVE_DIR` 或设置页配置的「自定义归档目录」，默认归档至系统文档目录下的 `DeepSeekHarnessFileLauncher/Archived_Docs` 日期文件夹；原文件保留。成功复制会记录到 `archive.json`，面板显示 **已归档** 标记并支持单独筛选。
- **模型工具** `file_launcher`：`list`（含跨会话 `sent`）/ `sessions` / `pin` / `unpin` / `archive`。

## 安装与使用

把本目录作为 DSH bundle 通过 **插件 → 添加插件** 安装，刷新页面。三个快捷入口：对话标题栏右侧工具区的文件夹按钮、输入框工具行左侧的 **文件** 胶囊、右侧边栏 **+** 指南中的「文件启动器」卡片。任一点击即可打开面板。

**从 GitHub 安装：**

1. 打开 DSH 的 **插件 → 添加插件**
2. 安装源选 **默认 / GitHub**（中国大陆镜像源主要用于 npm 包，不一定代理 GitHub）
3. 输入仓库地址：`https://github.com/ZOU2850/dsh-file-launcher`
4. 点击 **安装**
5. 安装完成后**完全退出并重开 DSH**（1.4.x 改了 Host 扫描与设置模块，重启才加载新模块）

如果 GitHub 安装失败，可在同一输入框填本地目录：

```text
D:\Downloads\文件打开助手插件dsh适配改造\dsh-file-launcher
```

已安装同名插件时，先移除/禁用旧版本再安装，避免重复实例。

1. 选择范围：当前对话、我发送的、当前项目、收藏或历史对话。
2. 点击文件行在面板内预览；图片/Office 可直接切换上一个、下一个。
3. 行尾 **打开方式 ▾** 或右键文件行，可在点击位置弹出可滚动卡片：预览、本机打开、复制路径/引用、插入引用、收藏、归档、删除。

### 设置

在 DSH 底部头像菜单进入 **设置**，左侧导航会出现 **文件启动器**：

**外观**

- 主题：跟随 DSH / 浅色 / 深色 / 跟随系统
- 切换后**立即应用**到已打开的侧边栏，并自动写入 `settings.json` 和当前浏览器本地缓存，跨重启保留

**行为、预览与路径**

- 面板打开时自动刷新开关，以及刷新间隔（5–300 秒，默认 60 秒）
- 默认打开范围（当前对话 / 我发送的 / 当前项目）
- 「我发送的」项目/会话分组是否默认收起
- PDF/Office 最大渲染页数（1–40）、渲染 DPI（80–160）
- 单次加载上限（100–2000）
- 自定义归档目录，并展示当前数据目录、我发送的索引与实际归档路径

设置写入 `$DSH_HOME/file-launcher/settings.json`，不写入 profile 的 `cordis.patch.yml`，因此插件升级/重装不会覆盖。

## 兼容与升级

- 在 **DSH Desktop 0.2.2-rc.3 / Electron 44.7 / Node 24.21** 上测试。
- 只使用公开扩展点：`ctx.tools`、`ctx.connection.fetch`、Cordis 服务、Client `slots` / `sidebarRightTabs` / `locale` / remotes；**没有 import 任何 `@deepseek-ai/dsh-*` 包**，可选能力（`officeKit`、`fileDrag`）不阻塞插件启动与激活。
- 设置页通过 `settings.section` 懒注册：旧版 DSH 没有该 slot 时只是没有设置页，不会阻止插件加载；如果未来 DSH 改这个 slot 的契约，需要随版本适配。
- 升级方式：重新安装/启用 bundle 后**完全退出并重开 DSH**，再刷新页面（如新增 Host 路由或设置字段，仅刷新页面可能仍使用旧的 Host 模块）。`pins.json`、`sent-index.json`、`archive.json`、`settings.json`、`deleted.json` 都在 `$DSH_HOME/file-launcher/`，不会因插件升级丢失。
- 社区分发时请保持 `package.json` 中的 `dsh.bundle` / `dsh.client` / `engines.dsh` 与 `LICENSE` 完整；无需启用启动期阻塞标记。

## 性能与资源

- **不消耗模型 token**：面板、预览、自动刷新都在浏览器/Host 本地执行，不调用 LLM。
- 只有模型主动调用 `file_launcher` 工具时才占上下文；默认最多 60 行，可通过工具参数 `limit` 降到 1 行。
- 自动刷新默认 **60 秒**；在设置里可以关闭或调整（5–300 秒）。刷新请求带 `AbortController`，不会在慢会话上堆叠请求。
- 面板默认最多加载 800 行；PDF 默认最多 20 页（可调到 40 页），普通 PDF 直接按 Host 磁盘路径渲染避免冗余 base64 传输。
- 内存主要是 DSH/Chromium 本身与当前打开的预览图；`$DSH_HOME/file-launcher/previews` 下生成的临时预览缓存会自动清理上限。

## 限制

- 仅由 shell 命令创建、且没有出现在工具结果或 `present` 中的文件，只会归入「当前项目」，不会归到具体对话。
- 本机打开能力取决于 Host 是否为桌面端。
- **PDF 页面渲染依赖本地 `pdfinfo` / `pdftoppm`**；缺失时预览会提示，并保留“在侧边栏打开”。
- **文件夹 @ 路径** 只提供资源管理器入口，不会展开或递归扫描文件夹内容。
- 面板内 Office 预览依赖当前 profile 的 `office-kit` 提供方；缺失时回退到右侧边栏原生预览。
- **空壳只覆盖用户 @ 文件和交付文件**；纯工作区文件如果被外部删除、又从未被对话引用，就没有历史路径可以保留。跨盘移动且没有新引用时也会保留旧空壳。
- **定时刷新默认 60 秒轮询**，不是文件系统监听；刚创建的文件会在下一个周期出现，也可点击刷新即时获取。
- **我发送的** 只扫描最近 20 个顶层会话，并且逐个串行读取；首次访问时才构建索引，启动时不预热扫描，避免一次读取大量会话导致宿主内存峰值。索引持久化到 `$DSH_HOME/file-launcher/sent-index.json`，之后打开直接读索引，支持点击刷新重建。
- **插入引用 / 附件**：依赖宿主是否提供 `fileDrag` 与编辑框拖放接收器；不可用时自动退回 `@路径` 文本或剪贴板。
- **用户 @ 引用**：用户在消息里用纯文本 `@路径` 发送的文件（包括桌面绝对路径）会被解析，并出现在 **用户** / **我发送的** 里，不再只识别浏览器附件。
- **删除文件** 是永久操作，无法撤销；归档和收藏都不会删除文件。
- 收藏是当前机器的全局清单，不随会话导出同步；收藏只保护路径记忆，不会移动或删除文件。
- 归档是普通文件副本，没有版本历史；原文件始终保留。
- 规范化图片附件没有扩展名，Host 会在 `$DSH_HOME/file-launcher/previews` 发布带扩展名的预览链接，附件对象本身仍是文件本体。

详见 [`docs/DETAIL.md`](docs/DETAIL.md)；QA 与资源测量见 [`docs/QA.md`](docs/QA.md)。
